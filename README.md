# ValuVeda Wellness — Final Website

Upload the contents of this folder to the GitHub repository root.

## Assets
All website assets are inside `assets/`. Do not rename them unless the HTML/JS references are also changed.

Included:
- Product front/back
- Logo
- How-to-use image
- How-to-use/brand video
- 5 benefit cards
- 3 customer-experience cards
- 15 ingredient images
- Lifestyle/product texture assets

## Order flow
The product page includes Add to Cart -> COD checkout. The form is configured to send order details through FormSubmit to Info@valuveda.com. FormSubmit requires the receiving email to be confirmed the first time.

No admin panel is required.

## Privacy
No registered/office address is displayed on the public product page.
